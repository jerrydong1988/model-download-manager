# v0.4.2 — 薄荷绿界面，右上角切换明暗

这次正式版仍只做模型下载。页面布局和操作与 v0.4.0 相同，配色改为浅灰与薄荷绿，并可以在主界面直接切换明暗。

- **主界面一键切换明暗**：每个页面右上角都可以在浅色和深色之间切换，并立即保存。当前是「跟随系统」时，点一下会改成与当时外观相反的固定主题。
- **薄荷绿界面**：浅灰背景、白色工作区。当前导航图标、主按钮、进度和选中态使用深薄荷绿，焦点环为靛蓝。应用图标和托盘图标改为同一绿色。
- **下载行为不变**：量化选择、粘贴链接、磁盘检查、完成后校验、按仓库管理队列、本地库和收藏与 v0.4.0 相同。

## 升级说明

- 从 v0.4.0 升级沿用现有配置、任务和下载路径，不需要迁移。
- 托盘常驻时，请先从托盘菜单退出旧版本，再运行新安装包或免安装程序。
- 若原来选择「跟随系统」，使用右上角按钮后会改为固定的浅色或深色。要恢复跟随系统，到「设置 → 外观」重新选择。
