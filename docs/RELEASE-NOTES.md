# v0.5.0 — 应用内在线升级

这个版本加入应用内自动升级：不再需要手动去发布页下载安装包，应用会自己发现新版本并一键完成下载安装与重启。

- **启动自动检查**：打开应用数秒后静默检查新版本，发现新版弹出提示并可一键跳转到设置页；检查失败不打扰，可在「设置 → 关于与更新」关闭。
- **一键升级**：设置页「关于与更新」显示当前版本、新版本号与更新说明，点「立即更新」即开始下载（带进度条），完成后自动安装并重启；未完成的下载任务重启后自动继续。
- **更新源可配镜像**：更新检查默认走 GitHub Releases；国内网络可在设置中填写镜像 `latest.json` 完整地址（与 HuggingFace 镜像同样思路），保存后生效。
- **数字签名校验**：更新包使用 minisign 签名（GitHub Actions 构建时签名，应用安装前校验签名与版本号），来源不可信或签名不符一律拒绝安装。
- **其余不变**：模型下载、本地库、任务队列、外观与快捷键与 v0.4.2 完全相同。

## 升级说明

- 从 v0.4.x 升级沿用现有配置、任务和下载路径，不需要迁移。
- **v0.4.2 及更早版本没有应用内升级，需手动下载安装本版本最后一次**；此后版本均可自动升级。
- 免安装（绿色）版不支持应用内升级，请继续使用安装包或手动替换程序。
- 托盘常驻时，请先从托盘菜单退出旧版本，再运行新安装包或免安装程序。

## 发布附件

- `Model-Download-Manager_0.5.0_x64-setup.exe`：Windows x64 NSIS 安装包。
- `Model-Download-Manager_0.5.0_x64.exe`：Windows x64 免安装程序。
- `SHA256SUMS.txt`：上述文件的 SHA-256 校验清单。
- `latest.json`：应用内升级的更新清单（含安装包 minisign 签名），由 CI 自动生成。

附件由 GitHub Actions 在 Windows 上执行回归测试、编译和打包后生成，发布流程核对 SHA-256。更新包带 minisign 签名（用于应用内升级校验）；安装程序本身未做 Windows 代码签名证书签名。
