本次稳定版本修复下载完整性、暂停取消、路径冲突和前端状态同步等 11 项功能缺陷。

- 分段状态先持久化再预分配文件；缺失或损坏的断点元数据不会再把未下载内容误判为完成。
- 单流重试和分块请求校验文件版本，避免远端更新时混合新旧数据。
- 同一最终文件、临时文件或元数据路径只允许一个任务占用；新建非默认 revision 使用独立目录。
- 修复数据块超过限速桶容量时的永久等待；HTTP 请求、响应体及限速等待均可暂停或取消，增加读取空闲超时。
- 仓库详情按来源、仓库、revision 和保存目录区分任务，支持 HuggingFace 带斜杠的 revision。
- 快照刷新以服务端状态为准并保留请求期间的事件；任务更新序号支持合法进度归零并拒绝过期事件。
- 修复磁盘根目录选择，启用 SOCKS5/SOCKS5h 代理。
- 新增 Windows CI，自动执行回归测试、构建 NSIS 安装包与便携程序，并生成 SHA-256 校验清单。

升级说明：

- 已有任务继续使用保存的原路径。默认分支的新下载路径不变。
- 新建非默认 revision 下载到 `<下载目录>/.mdm-revisions/<revision 的 UTF-8 十六进制编码>/<仓库ID>/<文件路径>`，避免与仓库中的同名目录冲突。
- 有效且版本一致的未满长度旧断点继续续传；缺少有效元数据或远端版本变化的断点从头下载。旧单流 `.part` 已达到完整长度时，因无法区分旧版预分配空洞，也会重取响应体；已有正式完成文件不受影响。
- 历史队列若存在目标路径冲突，会明确报错；可清理冲突记录或改用其他下载目录。
