# v0.3.0 — 全新界面与统一图标

本次正式版围绕「浏览仓库 → 选择文件 → 批量下载」重新整理界面，并更新应用与系统托盘图标。

- **雾白与石墨界面**：重设计浏览仓库、下载队列、本地模型库和设置页面，使用中性底色、蓝紫强调色、清晰的文字层级和留白。
- **更清晰的文件选择与操作**：仓库使用对齐的目录布局，文件选中状态覆盖整行，批量下载和设置操作保持可见。
- **通知避让操作区**：应用内通知根据底部操作条的位置调整显示，减少遮挡，支持多条通知同时出现。
- **70 枚统一图标**：12 枚原创品牌与业务图标、58 枚 Lucide 通用图标，统一线条与尺寸规范，覆盖导航、模型文件、下载状态及操作。
- **应用与托盘新标识**：更新 Windows 应用、安装包、网页图标；托盘采用适合小尺寸显示的简化轮廓。项目提供 SVG、PNG、ICO、React 组件和可离线搜索的图标目录。
- **浅深色与无障碍**：保留浅色／深色／跟随系统和快捷键；图标明确区分装饰与可访问名称，下载状态同时使用图形与文字表达。

## 升级说明

- 从 v0.2.1 升级沿用现有配置、任务与下载文件路径，无新增数据迁移。
- 托盘常驻时，请先从托盘菜单退出旧版本，再运行新安装包或免安装程序。
- 本版包含 v0.2.1 的全部功能缺陷修复。更早版本升级的断点及非默认 revision 路径兼容规则见 [v0.2.1 发布说明](https://github.com/jerrydong1988/model-download-manager/releases/tag/v0.2.1)。
