# v0.4.0 — 选对文件，下完可核对

这次正式版仍只做模型下载。它减少一次勾上所有量化档的情况，并在下载前看磁盘、下载后核对校验和。

- **按量化档和分片选择**：同一仓库有多档权重时，默认只选推荐的一档和配套投影器。可以改选其他档，或按分片组一次选齐。
- **粘贴链接打开仓库**：搜索框接受 HuggingFace 与 ModelScope 的仓库页、blob 和 resolve 链接。链接指向单个文件时会预选该文件。
- **下载前检查磁盘**：目标盘放不下已选文件时不能开始下载。分段预分配后剩余空间低于 1 GB 时给出提示，仍允许继续。
- **完成后校验**：保留 HuggingFace LFS oid 和 ModelScope 的 Sha256。校验在后台进行，不一致会标为失败并删除损坏文件。本地库显示已校验、无校验和、正在校验或不一致。
- **按仓库管理队列**：同一来源、仓库和 revision 的任务收成一批，可暂停、继续或重试失败项。整批结束后只发一条通知。
- **可核对的本地库**：记住展开和筛选；同一相对路径出现在多个扫描根时标出重复；目录显示 revision；远程大小或校验和不同的文件标为可更新，不自动覆盖。可以清理取消后留下的 `.part`，不删除已完成文件。
- **最近打开与收藏**：只保存在本机，显示在浏览页，不需要账号。

## 升级说明

- 从 v0.3.0 升级沿用现有配置、任务和下载路径。旧任务没有校验和时按「无校验和」读取，不需要迁移。
- 托盘常驻时，请先从托盘菜单退出旧版本，再运行新安装包或免安装程序。
- 已暂停的同仓库任务会让这一批的完成通知等到该任务结束或取消。单个文件的暂停、取消和打开位置保持不变。
- 「可更新」只提示差异。大小相同的本地文件仍会被视为已完成，需要先删除本地文件再重新下载。
