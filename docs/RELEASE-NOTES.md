# v0.5.3 下载完整性与文件定位

- 断点续传和多连接下载会核对远端文件版本。服务器缺少可靠的版本标识时，改为从头获取完整文件。Windows 下断点被其他程序占用时，任务会给出清理错误，可在释放文件后重试。
- 正确处理服务器明确声明的零字节文件。如果响应未提供长度，下载器会保留临时文件，或在有预期 SHA-256 时把内容交给校验流程。应用在校验通过后提示下载成功。
- 文件列表可以识别本地已有的模型。镜像文件经 SHA-256 确认一致后可复用，避免重复下载。文件被移动或内容发生变化时会重新核对。
- 下载队列和完成通知可定位到单次任务自选的目录。Windows 直接在资源管理器中选中文件，支持中文、空格和逗号。

使用现有安装版可在应用内检查更新。手动安装请选择本次发布的 x64 安装包。
