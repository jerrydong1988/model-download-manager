## 下载与数据完整性

- 旧单流断点可转换为分段元数据，保留已下载前缀；前缀指纹在续传前后相同。
- 暂停、继续、异常结束后恢复均保留断点。旧任务兼容测试只验证增量续传，没有把完整大文件下载完成作为该轮验收条件。
- 本地确定性 Range 服务验证多连接请求、内容 SHA-256、暂停续传及分块元数据。
- 不支持 Range 的服务回退单流；完成后移除 `.part` 和 `.part.json`。
- 小文件的真实源下载与独立下载 SHA-256 一致。网络/CDN 抖动会影响速度，单次测量不能作为普遍性能保证。

## 目录、revision 与桌面行为

- 多扫描根支持聚合、添加/移除和重启持久化，默认下载目录保留。
- 文件分类覆盖权重、投影器、权重矩阵、配置和其他文件；目录树聚合与磁盘统计一致。
- 非默认 revision 的任务与路径可与默认 revision 并存，自定义 commit SHA 下载已验证。
- 无效 revision 显示错误；ModelScope 支持自定义 revision 文本。
- 深浅主题、托盘后台下载、应用内提示和系统通知横幅已验证。

## 已知覆盖限制

1. Windows 11 系统通知的自动点击未完成，不能把通知横幅可见等同于点击唤起已验证。
2. `.part` 分段续传会按总文件长度预分配空间；这与“已下载字节数”不是同一概念。
3. 首轮 HF 小文件曾出现网络停滞，复测通过。
4. 测试仓库没有标签时，使用自定义 commit SHA 验证非默认 revision。
5. 关闭时落盘状态与完全退出的边界仍有历史观察项；读屏、部分系统缩放与高对比度场景未完成覆盖。
